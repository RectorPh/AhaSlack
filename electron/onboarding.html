Welcome to AhaSlack

Connect your Telegram in about 5 minutes.

◌
Your login stays on this Mac. AhaSlack talks to Telegram directly, with no server in between.
Step 1 of 4

Install uv

AhaSlack's engine is a small Python program. uv runs it and fetches what it needs, so you don't have to set up Python yourself.

  1. Click Install in Terminal. Terminal opens and runs the official installer from astral.sh:
    curl -LsSf https://astral.sh/uv/install.sh | sh
  2. Wait for it to say everything's installed!. It takes a few seconds.
  3. Come back here. This step ticks itself off.
Step 2 of 4

Get your Telegram API keys

Telegram gives every app that reads your own account a pair of keys: an api_id (a number) and an api_hash (a long code). You create them once, for free.

  1. Open my.telegram.org (button below) and enter your phone number in international format, for example +84 912 345 678.
  2. Telegram sends a confirmation code to your Telegram app (not by SMS). Type it in on the website.
  3. Click API development tools.
  4. Fill in the Create new application form. Only the first two fields matter:
    App titleAhaSlack
    Short nameahaslack
    URLleave empty
    PlatformDesktop
    Descriptionleave empty
    Then click Create application.
  5. The page now shows App api_id and App api_hash. Keep that tab open: you'll paste both in the next step.
If the form shows "ERROR", try again with a different short name, or turn off a VPN or ad blocker for that page. It's a known quirk of the site.
Keep the api_hash private. Together with a login, it gives access to your account. AhaSlack stores it only on this Mac, in ~/.config/telegram-inbox/, readable only by you.
Step 3 of 4

Log in to Telegram

You log in once, in Terminal, so your code and password never pass through the app's window. AhaSlack then appears on Telegram as a new device (Settings → Devices), and you can log it out from there at any time.

  1. Click Log in with Terminal.
  2. Answer the questions:
    api_id: 12345678 # the number from step 2
    api_hash (hidden): # paste it; nothing shows as you type
    Please enter your phone (or bot token): +84912345678
    Please enter the code you received: 12345 # sent to your Telegram app
    Please enter your password: # only if you use two-step verification
    Logged in as Your Name (@yourhandle).
  3. When Terminal says Logged in as …, come back here. This step ticks itself off.
Telegram also posts a "new login" message in your Telegram app. That's expected: it's AhaSlack.
Step 4 of 4

Make it yours

Logging in created a settings file, config.toml. A few lines in it make AhaSlack much smarter about what needs you.

  1. my_keywords = ["Your Name", "yourhandle"]: the names people use for you. A group that says one of them goes to Needs you. (@mentions and replies to you are found automatically.)
  2. timezone = "Asia/Ho_Chi_Minh": your timezone, for message times.
  3. sending_enabled = true: lets you send, reply, react and edit from AhaSlack. It's off until you turn it on.
  4. mark_read_enabled = true: lets AhaSlack mark chats read on Telegram, like Slack does when you open a channel.
  5. Optional: vip_users (people whose messages always matter) and ignore_chats (groups to treat as noise).

Save the file. AhaSlack reads it every time it starts.

Optional

Turn on the Inbox Manager

The Inbox Manager answers questions like "What needs me today?". It runs on Claude through Claude Code and uses your Claude Code login, so you don't need an API key. Everything else in AhaSlack works without it.

  1. Install Claude Code from claude.com/claude-code (button below).
  2. Run claude once in Terminal and log in.
The Inbox Manager can only read. It has no way to send, edit or mark anything on Telegram, and what you ask it goes to Claude.
All set

Open AhaSlack

Steps 1 to 3 are needed. When they're ticked, open AhaSlack.

The first start takes a minute: it downloads AhaSlack's Python packages and reads your chats. After that, it opens in seconds and stays in sync live.
